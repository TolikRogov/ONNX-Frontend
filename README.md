## О проекте

Этот инструмент создан для того, чтобы создавать представление нейронной сети из формата ONNX в виде графа для дальнейшего его оптимизационного обхода или исполнения. Контроль корректности созданного представления можно производить по создающемуся Graphviz изображению.

## Зависимости

Разработка проекта производилась на операционной системе MacOS на архитектуре ARM.
Для корректной работы инструмента требуется установить следующие библиотеки:

- [Protocol Buffer Compiler](https://protobuf.dev/installation/)
- [Graphviz](https://graphviz.org/download/)

## Использование

Для работы данного инструмента необходимо при запуске указать путь до ONNX файла нейронной сети. Произвести установку и запуск можно прописав следующие команды, в этом примере использована нейронная сеть, находящаяся в директории 'onnx/yolov5nu'. Клонирования репозитория может занять продолжительное время в связи с наличием объемных моделей, на которых производилась тестирование инструмента.

```
git clone https://github.com/TolikRogov/ONNX-Frontend;
cd ONNX-Frontend;
make run-release ARGS=onnx/yolov5nu/yolov5nu.onnx;
```

Результатом работы программы будет информация в терминале о модели, содержащейся в файле, а также изображение графа этой модели в той же директории, что и сам файл модели нейронной сети. Также генерируется временная директория, содержащая файл с txt представлением модели этой сети.

## Описание

### Таблица поддерживаемых операций

| Операция (`op_type`)     | Описание                                                  | Входы (`inputs`)                                                                                                                                                 | Выходы (`outputs`)                                                                                                                       | Примечание                                                                                              |
| :----------------------- | :-------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------ |
| **`Conv`**               | Сверточный слой                                           | 1. Входной тензор (например, `images`) <br> 2. Тензор весов (`*.weight`) <br> 3. Тензор смещения (`*.bias`)                                                      | Тензор результата свертки                                                                                                                | Основной строительный блок сети.                                                                        |
| **`Sigmoid`**            | Функция активации                                         | Входной тензор                                                                                                                                                   | Тензор после применения Sigmoid                                                                                                          | Используется как часть активации SiLU (Swish).                                                          |
| **`Mul`**                | Поэлементное умножение                                    | 1. Тензор (например, результат свертки) <br> 2. Тензор (например, результат Sigmoid)                                                                             | Тензор результата умножения                                                                                                              | Вместе с `Sigmoid` образует активацию SiLU (Swish): `x * sigmoid(x)`.                                   |
| **`Add`**                | Поэлементное сложение                                     | 1. Тензор (например, результат из одного пути) <br> 2. Тензор (например, результат из другого пути)                                                              | Тензор суммы                                                                                                                             | Используется для создания Residual connections (остаточных связей) в блоках C2f.                        |
| **`Concat`**             | Конкатенация тензоров                                     | Список из нескольких тензоров                                                                                                                                    | Единый тензор, полученный объединением входных                                                                                           | Объединяет тензоры по оси, указанной в атрибуте `axis` (обычно ось каналов, `axis: 1`).                 |
| **`MaxPool`**            | Операция подвыборки (пулинг)                              | Входной тензор                                                                                                                                                   | Тензор после применения пулинга                                                                                                          | Используется в блоке SPPF (Spatial Pyramid Pooling - Fast) для создания многомасштабного представления. |
| **`Resize`**             | Изменение пространственного размера                       | 1. Входной тензор <br> 2. (пустая строка `""` - часто для roi) <br> 3. Тензор с параметрами масштабирования                                                      | Увеличенный или уменьшенный тензор                                                                                                       | Используется для апсемплинга (upsampling) в Neck-части сети (FPN).                                      |
| **`Reshape`**            | Изменение формы тензора                                   | 1. Входной тензор <br> 2. Тензор с новой формой                                                                                                                  | Тензор новой формы (например, `/model.24/Reshape_output_0`)                                                                              | Подготавливает тензоры для финальной обработки детекций.                                                |
| **`Transpose`**          | Перестановка осей тензора                                 | Входной тензор                                                                                                                                                   | Тензор с переставленными осями                                                                                                           | Используется в блоке DFL (Distribution Focal Loss) для изменения порядка осей перед `Softmax`.          |
| **`Softmax`**            | Функция Softmax                                           | Входной тензор                                                                                                                                                   | Тензор, где значения преобразованы в вероятности                                                                                         | Применяется по оси, указанной в атрибуте `axis`.                                                        |
| **`Slice`**              | Извлечение среза тензора                                  | 1. Входной тензор <br> 2. Тензор начала среза (`starts`) <br> 3. Тензор конца среза (`ends`) <br> 4. Тензор шага (`axes`) <br> 5. (иногда) Тензор шага (`steps`) | Вырезанный тензор                                                                                                                        | Используется в голове детекции для разделения предсказаний на координаты box-ов и confidence scores.    |
| **`Sub`**                | Поэлементное вычитание                                    | 1. Тензор (уменьшаемое) <br> 2. Тензор (вычитаемое)                                                                                                              | Тензор разности                                                                                                                          | Входит в состав формул для декодирования предсказанных bounding box-ов.                                 |
| **`Div`**                | Поэлементное деление                                      | 1. Тензор (делимое) <br> 2. Тензор (делитель)                                                                                                                    | Тензор частного                                                                                                                          | Также используется при декодировании bounding box-ов.                                                   |
| **`Relu`**               | Функция активации ReLU                                    | Входной тензор                                                                                                                                                   | Тензор после применения ReLU                                                                                                             | Используется после каждой свертки для внесения нелинейности.                                            |
| **`Dropout`**            | Операция регуляризации                                    | Входной тензор                                                                                                                                                   | 1. Тензор после dropout <br> 2. Маска (не используется)                                                                                  | Случайно обнуляет часть нейронов для борьбы с переобучением.                                            |
| **`GlobalAveragePool`**  | Глобальный средний пулинг                                 | Входной тензор                                                                                                                                                   | Тензор, где каждый канал усреднен до одного значения                                                                                     | Преобразует карты признаков в вектор перед классификацией.                                              |
| **`Split`**              | Разделение тензора на несколько частей                    | 1. Входной тензор <br> 2. (Опционально) Тензор с размерами частей (`split`)                                                                                      | Несколько выходных тензоров                                                                                                              | Разделяет тензор на несколько меньших тензоров по указанной оси                                         |
| **`Shape`**              | Получение формы тензора                                   | Входной тензор                                                                                                                                                   | Тензор, содержащий размерности входного тензора                                                                                          | Возвращает одномерный тензор с размерами исходного тензора                                              |
| **`Gather`**             | Сбор элементов по индексам                                | 1. Входной тензор с данными <br> 2. Тензор с индексами                                                                                                           | Тензор, собранный по указанным индексам                                                                                                  | Извлекает элементы из тензора по заданным индексам                                                      |
| **`Unsqueeze`**          | Добавление новых осей (измерений)                         | 1. Входной тензор <br> 2. Тензор с осями для добавления                                                                                                          | Тензор с дополнительными размерностями                                                                                                   | Увеличивает ранг тензора, добавляя новые оси                                                            |
| **`MatMul`**             | Матричное умножение                                       | 1. Первый тензор <br> 2. Второй тензор                                                                                                                           | Тензор - результат матричного умножения                                                                                                  | Выполняет умножение матриц (если тензоры имеют больше 2 измерений, применяется broadcast)               |
| **`Cast`**               | Преобразование типа данных                                | Входной тензор                                                                                                                                                   | Тензор с новым типом данных                                                                                                              | Изменяет тип данных тензора (например, из int64 в float32)                                              |
| **`Range`**              | Генерация последовательности чисел                        | 1. Начальное значение (`start`) <br> 2. Конечное значение (`limit`) <br> 3. Шаг (`delta`)                                                                        | Тензор с последовательностью чисел                                                                                                       | Создает одномерный тензор с арифметической прогрессией                                                  |
| **`ConstantOfShape`**    | Создание тензора, заполненного константой, заданной формы | Тензор с целевой формой (`shape`)                                                                                                                                | Тензор указанной формы, заполненный заданным значением (по умолчанию 0)                                                                  | Полезно для создания тензоров определенной формы с постоянным значением                                 |
| **`Expand`**             | Расширение тензора до указанной формы                     | 1. Входной тензор <br> 2. Тензор с целевой формой                                                                                                                | Тензор расширенной формы                                                                                                                 | "Растягивает" тензор, повторяя его элементы до достижения целевой формы (broadcast)                     |
| **`BatchNormalization`** | Нормализация по батчу                                     | 1. Входной тензор (`X`) <br> 2. Тензор масштаба (`scale`) <br> 3. Тензор смещения (`B`) <br> 4. Среднее (`mean`) <br> 5. Дисперсия (`var`)                       | 1. Нормализованный выходной тензор (`Y`) <br> 2. (Опционально) Среднее после выполнения <br> 3. (Опционально) Дисперсия после выполнения | Стабилизирует обучение, нормализуя активации по батчу                                                   |
| **`Flatten`**            | Преобразование в одномерный тензор                        | Входной тензор                                                                                                                                                   | Тензор, сплющенный в 2D (сохраняет размер батча)                                                                                         | Преобразует многомерный тензор в двумерный: `[batch, ...]` → `[batch, все_остальное]`                   |
| **`Gemm`**               | Обобщенное матричное умножение                            | 1. Тензор A <br> 2. Тензор B <br> 3. (Опционально) Тензор C                                                                                                      | Тензор - результат `alpha * A * B + beta * C`                                                                                            | Выполняет линейное преобразование, часто используется в полносвязных слоях                              |

В случае наличия неподдерживаемой операции программа выдаст соответствующее исключение.

В директории onnx содержатся другие модели нейронных сетей, на которых можно проверить правильность работы инструмента.
