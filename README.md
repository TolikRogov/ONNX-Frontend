# ONNX-Frontend

1. from ultralytics import YOLO -> yolov5nu.pt
2. path = model.export(format="onnx") -> yolov5nu.onnx
3. https://github.com/onnx/onnx/blob/main/onnx/onnx.proto -> onnx.proto
4. https://github.com/onnx/onnx/blob/main/docs/IR.md -> yolov5nu.txt:

```
protoc --decode=onnx.ModelProto onnx.proto < yolov5nu.onnx > yolov5nu.txt
```

Конечно, вот та же таблица, оформленная с использованием синтаксиса Markdown, который идеально подходит для вставки в документацию, README-файлы на GitHub, Notion или любой другой текстовый редактор, поддерживающий Markdown.

### Таблица операций модели YOLOv5

| Операция (`op_type`)    | Описание                            | Входы (`inputs`)                                                                                                                                                 | Выходы (`outputs`)                                                                            | Примечание                                                                                              |
| :---------------------- | :---------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------ |
| **`Conv`**              | Сверточный слой                     | 1. Входной тензор (например, `images`) <br> 2. Тензор весов (`*.weight`) <br> 3. Тензор смещения (`*.bias`)                                                      | Тензор результата свертки (например, `/model.0/conv/Conv_output_0`)                           | Основной строительный блок сети.                                                                        |
| **`Sigmoid`**           | Функция активации                   | Входной тензор (например, `/model.0/conv/Conv_output_0`)                                                                                                         | Тензор после применения Sigmoid (например, `/model.0/act/Sigmoid_output_0`)                   | Используется как часть активации SiLU (Swish).                                                          |
| **`Mul`**               | Поэлементное умножение              | 1. Тензор (например, результат свертки) <br> 2. Тензор (например, результат Sigmoid)                                                                             | Тензор результата умножения (например, `/model.0/act/Mul_output_0`)                           | Вместе с `Sigmoid` образует активацию SiLU (Swish): `x * sigmoid(x)`.                                   |
| **`Add`**               | Поэлементное сложение               | 1. Тензор (например, результат из одного пути) <br> 2. Тензор (например, результат из другого пути)                                                              | Тензор суммы (например, `/model.2/m/m.0/Add_output_0`)                                        | Используется для создания Residual connections (остаточных связей) в блоках C2f.                        |
| **`Concat`**            | Конкатенация тензоров               | Список из нескольких тензоров (например, `input: "/model.2/cv1/act/Mul_output_0"` и `input: "/model.2/cv2/act/Mul_output_0"`)                                    | Единый тензор, полученный объединением входных (например, `/model.2/Concat_output_0`)         | Объединяет тензоры по оси, указанной в атрибуте `axis` (обычно ось каналов, `axis: 1`).                 |
| **`MaxPool`**           | Операция подвыборки (пулинг)        | Входной тензор (например, `/model.9/cv1/act/Mul_output_0`)                                                                                                       | Тензор после применения пулинга (например, `/model.9/m/MaxPool_output_0`)                     | Используется в блоке SPPF (Spatial Pyramid Pooling - Fast) для создания многомасштабного представления. |
| **`Resize`**            | Изменение пространственного размера | 1. Входной тензор <br> 2. (пустая строка `""` - часто для roi) <br> 3. Тензор с параметрами масштабирования (`/model.11/Constant_output_0`)                      | Увеличенный или уменьшенный тензор (например, `/model.11/Resize_output_0`)                    | Используется для апсемплинга (upsampling) в Neck-части сети (FPN).                                      |
| **`Reshape`**           | Изменение формы тензора             | 1. Входной тензор (например, `/model.24/cv2.0/cv2.0.2/Conv_output_0`) <br> 2. Тензор с новой формой (`/model.24/Constant_output_0`)                              | Тензор новой формы (например, `/model.24/Reshape_output_0`)                                   | Подготавливает тензоры для финальной обработки детекций.                                                |
| **`Transpose`**         | Перестановка осей тензора           | Входной тензор (например, `/model.24/dfl/Reshape_output_0`)                                                                                                      | Тензор с переставленными осями (например, `/model.24/dfl/Transpose_output_0`)                 | Используется в блоке DFL (Distribution Focal Loss) для изменения порядка осей перед `Softmax`.          |
| **`Softmax`**           | Функция Softmax                     | Входной тензор (например, `/model.24/dfl/Transpose_output_0`)                                                                                                    | Тензор, где значения преобразованы в вероятности (например, `/model.24/dfl/Softmax_output_0`) | Применяется по оси, указанной в атрибуте `axis`.                                                        |
| **`Slice`**             | Извлечение среза тензора            | 1. Входной тензор <br> 2. Тензор начала среза (`starts`) <br> 3. Тензор конца среза (`ends`) <br> 4. Тензор шага (`axes`) <br> 5. (иногда) Тензор шага (`steps`) | Вырезанный тензор (например, `/model.24/Slice_output_0`)                                      | Используется в голове детекции для разделения предсказаний на координаты box-ов и confidence scores.    |
| **`Sub`**               | Поэлементное вычитание              | 1. Тензор (уменьшаемое) <br> 2. Тензор (вычитаемое)                                                                                                              | Тензор разности (например, `/model.24/Sub_output_0`)                                          | Входит в состав формул для декодирования предсказанных bounding box-ов.                                 |
| **`Div`**               | Поэлементное деление                | 1. Тензор (делимое) <br> 2. Тензор (делитель)                                                                                                                    | Тензор частного (например, `/model.24/Div_1_output_0`)                                        | Также используется при декодировании bounding box-ов.                                                   |
| **`Relu`**              | Функция активации ReLU              | Входной тензор                                                                                                                                                   | Тензор после применения ReLU                                                                  | Используется после каждой свертки для внесения нелинейности.                                            |
| **`Dropout`**           | Операция регуляризации              | Входной тензор                                                                                                                                                   | 1. Тензор после dropout <br> 2. Маска (не используется)                                       | Случайно обнуляет часть нейронов для борьбы с переобучением.                                            |
| **`GlobalAveragePool`** | Глобальный средний пулинг           | Входной тензор                                                                                                                                                   | Тензор, где каждый канал усреднен до одного значения                                          | Преобразует карты признаков в вектор перед классификацией.                                              |
